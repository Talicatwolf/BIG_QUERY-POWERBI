### Processos

Primeiro foi necessário fazer uma cópia do Dataset para minha própria conta na Cloud, após confirmação de salvamento fui para o VSCode fazer um código de conexão e validação da integridade dos dados,
Contando a quantidade de nulos e dados faltantes, após a confirmação de integridade fiz a conexão entre o PowerBI e o dataset diretamente via Cloud, fiz os gráficos,
contendo controle deslizante para datas, gráfico de barras mostrando a contagem de ocorrências, gráfico de árvore para visualização de qual Borough tem maior incidência de crimes e gráfico de dispersão para comparação de categorias de crimes.
